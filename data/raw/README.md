# Raw data (not included)

DHS microdata cannot be redistributed. Register at https://dhsprogram.com, request access to
Ghana DHS 2022, and download the Stata (.DTA) versions. Place the zip files, unopened, in:

    data/raw/dhs/GH2022DHS/
        GHHR8CDT.zip   household recode (HR)
        GHPR8CDT.zip   household member recode (PR)
        GHKR8CDT.zip   children's recode (KR)
        GHGE8AFL.zip   GPS (optional)

Everything in this folder except this file is ignored by git.
